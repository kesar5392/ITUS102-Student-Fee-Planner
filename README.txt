## About the Project

The Student Fee and Scholarship Planner is a simple web application developed using HTML, CSS, and JavaScript. It calculates college fees after applying scholarship discounts and administration charges.

## Features

- Calculates tuition and laboratory fees.
- Supports Merit, Sports, and No Scholarship options.
- Applies scholarship discounts:
  - Merit: 20%
  - Sports: 10%
  - None: 0%
- Calculates a 5% administration charge on the fee subtotal.
- Displays the payable amount and semester-wise cumulative fees.
- Includes responsive styling for mobile and desktop screens.
- Validates fee inputs and the number of semesters.

## Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Fee calculations and validation
- **Git and GitHub** – Version control

## How to Run

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a web browser.
4. Enter the fee details and select a scholarship.
5. Click **Calculate** to view the results.

No additional package installation is required.

## Sample Calculation

**Input:**
- Tuition fee: ₹50,000
- Laboratory fee: ₹2,000
- Scholarship: Merit (20%)
- Semesters: 2

**Expected Output:**
- Subtotal: ₹52,000
- Scholarship discount: ₹10,400
- Administration charge: ₹2,600
- Payable per semester: ₹44,200
- Cumulative fee for two semesters: ₹88,400
